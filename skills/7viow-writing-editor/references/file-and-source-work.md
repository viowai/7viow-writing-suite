# File Edits, Format Changes and Source Gaps

Read when saving edits, converting a table/list/document structure, using supplementary material, or resolving a missing or conflicting source. Ordinary edits to a single supplied text do not need this reference.

## File edits

A user's instruction to edit a named file authorizes the stated local work. Read its current contents and applicable project instructions. Before applying a patch, re-read the affected text if it may have changed; reconcile concurrent changes from the actual text. Apply only the authorized patch, then read back the saved result and report meaningful changes with locations.

For Markdown, preserve the structures present in the file: frontmatter, links, headings, code fences, tables, lists, and template syntax where applicable. Do not inspect nonexistent structure types just to fill a checklist.

For a requested table/list/prose conversion, preserve comparison dimensions, sequence, hierarchy, and unique facts. Identify the source form, target form, permitted omissions, and required ordering when those affect meaning. Explain a material representation loss before making it.

Preserve time and numeric precision across the converted text and fields. A month, month-end, phase or approximate quantity remains at that precision; formatting does not establish an exact day or value. Keep factual cutoffs separate from generation or checking timestamps. If the target format requires a precise value, retain the source meaning and identify the conversion convention or unresolved value where the consumer needs it.

## Find the governing material

Read the current supplied source before wider history. For a missing or moved file, state the writing decision the search must resolve, follow relevant current pointers, and search exact wording before broad alternatives. Distinguish historical drafts, style samples, candidate plans and authoritative evidence. A failed search proves only what was absent from that scope.

Use supplementary evidence to verify, understand, or complete the requested work while preserving the user's selected disclosure scope. A true detail absent from the selected draft is not by itself an error. Distinguish correcting a known error from adding information or restoring a deletion; the latter requires the current task to authorize that expansion. More complete evidence does not automatically replace the user's selected wording or omissions.

Read conflicting passages and the user's applicable decisions. Distinguish a disagreement about fact, voice, wording, order or distribution. Apply the user's clear instruction to the dimension it controls; a wording preference does not itself create external evidence. Continue independent supported content while identifying a real unresolved claim.

Recovery ends when the next unit has usable authority or a precisely stated evidence gap. Reading an archive does not authorize moving, deleting or rewriting it. Sensitive material supplied for editing remains within that purpose.

## Finish the file operation

Read back the saved result and verify both the permitted change and its effect on surrounding meaning. A protected statement can become false when a related fact changes: a duration, total, or conclusion may no longer agree with its inputs. Complete the authorized edit and keep protected wording untouched, then report the specific remaining contradiction alongside the completed changes. Exact preservation alone does not establish consistency.

Report the changed location and useful result. If only a candidate was requested, return that candidate without writing the source file. A conversion must preserve the comparison dimensions and decision-relevant relationships, not merely the count of cells or paragraphs.
