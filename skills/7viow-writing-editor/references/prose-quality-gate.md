# 写作质量门禁

生成、修改或审阅文字前，按读者理解、正文用途和表达节制检查全部适用问题。超出当前额度或确认缺陷，就在授权范围内修改并复查实际交付文本。只审阅时报告问题位置、读者影响和需改善的结果；请求改法才给具体方案，不覆盖原稿。

## 读者理解

目标读者应能按实际阅读方式理解对象、动作、条件和关系。检查抽象词是否代替具体内容，内部简称和指代是否清楚，必要背景是否缺失。赋能、闭环、生态、链路、沉淀、复用、对齐、拉通等词，有明确含义和用途时可以保留；不能用它们代替应交代的内容。

确认一处影响理解的缺口，就补入材料支持的具体对象、动作、关系或解释，或删除没有内容的判断。不得为具体化编造事实。专业术语有定义、当前阅读单元内指向明确，或前文已交代背景时，保留必要简写；不让每句话重复完整背景。

## 正文用途

生成、修改和交付时，始终逐句判断文字对目标读者当前任务的具体作用：帮助理解什么、作出什么判断、完成什么行动，或实现什么创作目的。没有具体作用就删除，不等读者指出。标题、正文、讲述、附注和交付附言都适用；对内稿、对外稿和作者本人阅读版没有区别。

编写过程、取材缺口、自我辩解、修改记录和内部管理标签，不因涉及费用、服务范围或被称为重要事项就获得展示理由。不得把编写废话搬到附注、维护说明或内部版本继续交给读者。用户要求移除某内容时实际移除，不把移除要求写进成品。

有读者用途的内容，直接写材料支持的事实、关系、条件、动作或表达，不附带作者为何这样写、没有查到什么或本轮没有做什么的解释。资料不足约束可以作出的陈述，不自动生成待确认句、费用或服务范围说明。先利用已有材料解决；只有缺项实质阻止完成当前任务时，在工作对话中澄清，不往成品补话。

用户明确要求审稿意见、取材分析或操作规范时，按该任务交付实际需要的内容，仍逐句判断用途。Skill中供Agent执行的必要指令服务其读者任务，不能因此豁免空话。清理编写说明不得篡改已知事实和条件，也不把所有解释强制改成行动清单。

## 表达节制

| 问题类型 | 检查对象 | 回改 |
|---|---|---|
| 标点与强调 | 装饰性引号、解释性破折号、密集冒号分号、过量加粗 | 去掉无效强调与重复补充，把必要解释融入句子或独立成句，写清句间关系 |
| 句式与组织 | 机械二元对立、模板式递进、凑列序框架、非必要排比对仗、列表和模板标题 | 按实际时间、因果、并列或问题关系组织；保留真实比较和递进，不换另一套空洞模板 |
| 重复与收尾 | 段尾套路式拔高、收束套语、同义空转 | 留下表达最准的一处，删除没有新增信息的总结；保留有阅读用途的释义、跨章节回顾和真实过渡 |

数量上限见参数表。虚构对立、无依据道理、凑项凑数和无贡献复述，确认一处即改，不等达到词频。同一位置涉及多种问题时统一修复，不重复计算成果。

## 参数选择

默认使用严格。首次进入一个写作任务时，在正文外简短提示一次：默认采用严格文风，可切换标准，或直接指定引号、破折号等额度。提示后继续工作，不等用户选择。已有选择时直接沿用；连续修改及技能交接不重复提示。用户明确只要正文时遵守该格式，参数说明留到允许附加说明时。

| 参数 | 可选值与处理 |
|---|---|
| 风格 | 严格（默认）、标准、自定义。严格的每千字/全文频次预算为标准的一半，整数向下取整；加粗比例减半。句内/段内单次关系上限保持，语义缺陷不放宽 |
| 基于 | 自定义时选严格或标准，省略则沿用当前档位，首次省略取严格 |
| 逐项额度 | 可直接指定双引号、破折号、冒号、分号、对立句式、全文而是、递进句式、列序框架、段尾升华、排比、非必要列表、加粗次数、加粗比例、收束套语；未指定项继承所选档位 |
| 作用范围 | 默认当前稿件及后续修改；用户可明确本段、某页或整个项目。不自行写全局偏好或持久配置 |

接受自然语言设置，例如“风格=自定义，基于=严格，双引号每千字2对，破折号0处，加粗比例5%”。次数是非负整数，比例是0—100%；单位未写明沿用下表。明确设置可直接执行，只有单位或范围实质冲突才询问。修改参数时，简短回显实际改变的项目与作用范围，放在正文外。

用户明确指定的格式、逐字保留范围和修辞任务优先。普通风格样稿不会自动豁免额度；保留其声音，在当前设置内调整表达。三档都须保持事实、条件和作者立场，修复空话与虚构对立。数字是编辑约定，不是AI作者鉴定或质量分数。

## 额度、计数与保护范围

数字为允许上限，超过必须回改；0表示默认不用该类非必要形式。句、段、全文和每千字上限同时适用。读者理解和正文用途中的确认缺陷不设频次宽容额度。

| 参数 | 严格 | 标准 | 同时适用的限制 |
|---|---|---|---|
| 装饰性引号 | 每千字1对 | 每千字3对 | 单句最多1对；一对算一处 |
| 解释性破折号 | 每千字1处 | 每千字2处 | 每段最多1处；连续符号算一处 |
| 冒号 | 每千字2个 | 每千字4个 | 单句最多1个 |
| 分号 | 每千字1个 | 每千字3个 | 单句最多2个 |
| 对立句式 | 每千字1组 | 每千字2组 | 全文“而是”严格2处、标准5处；包含不是/并非等及拆句变体 |
| 递进句式 | 每千字1组 | 每千字2组 | 单句最多1组；包含不仅/不只/不但……还/也/更/而且等 |
| 非必要列序框架 | 每千字0组 | 每千字1组 | 包含第一第二第三、首先其次最后等完整列序框架 |
| 套路式段尾升华 | 每千字1处 | 每千字2处 | 连续2段同功能升华也触发 |
| 非必要排比 | 每千字0组 | 每千字1组 | 三个及以上同构分句算一组；连续3句同修辞骨架也触发 |
| 非必要列表 | 每千字1块 | 每千字2块 | 不以凑条数或维度拆分重复意思 |
| 强调加粗 | 每千字1处、占比最多5% | 每千字3处、占比最多10% | 标题、结构必需表头不计加粗占比 |
| 收束套语 | 每千字0处 | 每千字1处 | 包含换句话说、归根结底、本质上、真正重要的是等 |

每千字指任意连续1000个非空白可见字符，含标点；不足1000字按整稿检查。去掉格式标记和保护片段后取窗口，不靠加入无关文字稀释。独立备选稿分别计，同一稿件分章、分页、分轮修改不重置额度。中文按上表执行；英文沿用语义规则，不把中文字符限额冒称英文标准。

检查标题、导语、正文和结尾。真实引文、逐字转录、明确锁定的原句、代码、公式、URL、机器字段和必须保留的法律原文受保护；不计入额度，也不增加可用字数。引号本身不能证明是引文，普通词的装饰性引号仍计入；不能改用单引号、角引号或加粗逃避检查。

日期、词内连字符、代码和分隔线不算解释性破折号；时间、机器字段及必要清单引导符不按散文冒号分号计。必要步骤、比较表、FAQ、数据清单和用户指定格式保留，其解释文字仍检查。

明确要求的诗歌、口号组或修辞练习保留对应形式，不能以文章专业或需要节奏为由整篇免检。规则文档中明确标注的反面示例用于说明对应缺陷，检查其标注、准确性和必要长度；正向示例完整检查，不整体豁免示例章节。确需保护的原文与限额冲突时，保留原文，在正文外说明具体冲突，不冒称通过。

## 修订边界

保留数字、范围、限定、因果、立场、归属和各个独立事实；不把计划、推测或未审核内容写成确定结果。清理表达不等于删去必要解释，也不能只换标点或同义词、添加无关文字稀释密度，或编造经历来显得自然。

局部修改保留未要求调整的内容和已接受决定。来源核对、营销关系修正、长稿扩写压缩和连续反馈继承，使用当前技能对应方法。共用门禁说明必须达到的结果，场景方法提供做法，不增加另一轮独立审查。

## 反馈后的修订

在已有创作或改稿任务中，用户否定质量、指出缺陷，或针对当前稿件质问是否使用写作方法时，简短回答必要问题，并在同一轮交回修改后的实际内容供复审。沿用当前稿件、已确认选择和授权范围；解释、道歉、诊断、重写计划或再次询问是否要修改，都不能替代改后正文。

用户明确只评估、不改或暂停时，按该要求处理。缺失事实只阻止依赖它的内容，说明具体缺项并继续可完成的修订；不得编造事实来凑成稿。交回内容不授权发送、发布、安装或其他外部动作。

## 执行与完成

1. 先识别本次可改范围、实际文稿、当前参数和保护片段。局部修改读相邻段落与整稿重复结构，但不扩大写入权限。
2. 检查全部适用问题，定位读者理解、正文用途及表达节制的缺陷，确认有效计数。内部记原句位置与改法即可；不为每次写作生成报告或分数。
3. 按修订边界逐处回改。去掉无用修辞、合并重复意思、写清关系。
4. 重读改后实际正文，重算受影响计数并检查是否引入另一类问题。新稿查全文；局部编辑说明保护范围中仍存在的冲突。
5. 可改范围无超标、语义缺陷消除、必要信息保全，才交付完成稿。无法完成时说明具体未修项，不把参数降低或检查无命中当成修复。用户明确调整参数后按新设置检查。

工具可用时提供定位和原始计数，引用身份、必要结构及语义仍由上下文判断；无工具照样逐项检查，未运行不能冒称工具通过。交付通常直接给文稿，参数提示与必要说明放在文稿外，不把审稿记录带进正文。

## 幻灯片与协作

Deck逐页检查屏幕文字，再将整套屏幕文案按页序检查重复结构；讲述稿另作连续文本检查。标题仍计入，页码和生产字段标签不算正文。必要要点列表保留，其文字仍受其它规则约束；不把问题藏进讲述稿，也不为减少列表把屏幕改成长段落。

当前内容主责完成检查。下游修改了文字，就重查受影响单元；原样交接已检查的文稿可沿用已有结果。交接真实内容、参数、保护项和未解决问题，不强制调用另一个技能。
